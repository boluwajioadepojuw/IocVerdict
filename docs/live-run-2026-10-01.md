## Bug found and fixed during this run

The URLhaus lookup sent the full URL to the host endpoint (which expects
a hostname) and had no path for the API now requiring a key:

- URLs now reduce to their hostname before the lookup
  (urlhaus_host(), tested)
- With URLHAUS_API_KEY set, the v1/host API is used (Auth-Key header)
- Without a key, the public CSV of recent URLs is used instead, so the
  no-keys promise in the README stays true (_csv_listed(), tested)
